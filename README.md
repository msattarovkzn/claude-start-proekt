# Старт: своя база и первый проект — пошагово

Для каждого шага: что делаете → что появится.

## Что нужно заранее

- Приложение Claude на компьютере, вход в свой аккаунт, платная подписка (Claude Code входит в неё).
- Регистрироваться на GitHub **не нужно**: заготовку Claude скачает сам по ссылке.

---

## Шаг 1. Папка

Создайте на диске D папку `МойБизнес`.

**Появится:** пустая папка `D:\МойБизнес`.

---

## Шаг 2. Открыть папку в Claude

Приложение Claude → вкладка **Code** → новый разговор → выберите папку `D:\МойБизнес`.

**Появится:** окно разговора, вверху видно, что работа идёт в папке `МойБизнес`.

---

## Шаг 3. Вставить промпт — заготовка разложится сама

Скопируйте промпт [«Разложить заготовку»](prompts/01-zagotovka.md), вставьте в окно и отправьте.

Claude коротко скажет, что сделает, и попросит разрешение запустить команду. Нажмите **«Разрешить»**. Может спросить несколько раз — разрешайте: он работает только в этой папке и во временной.

**Появится** — Claude покажет список:

```text
D:\МойБизнес
├── CLAUDE.md            ← карта: Claude читает её первой
├── 00_DASHBOARD.md      ← главная: проекты в работе
├── Tasks Board.md       ← задачи (в «Сегодня» не больше трёх)
├── IDEAS_LOG.md         ← банк идей
├── DECISIONS_LOG.md     ← журнал решений
├── projects\
│   └── _ШАБЛОН.md       ← шаблон карточки проекта
├── agents\
│   ├── Заведение темы.md   ← регламент для /tema
│   └── План проекта.md     ← регламент для /proekt
├── .claude\commands\
│   ├── tema.md          ← команда /tema
│   └── proekt.md        ← команда /proekt
├── plans\               ← планы больших проектов
├── код\                 ← программы и боты
└── _archive\            ← старое, ничего не удаляем
```

Папка `.claude` в проводнике может быть скрытой — это нормально. Что каждый файл значит — в конце, «Что где лежит и зачем».

---

## Шаг 4. Новый разговор

**Обязательно.** Claude читает карту `CLAUDE.md` и видит команды только в начале разговора. В старом окне он их ещё не знает.

Откройте **новый разговор** в той же папке `D:\МойБизнес`.

**Проверка:** наберите `/` — в списке есть `tema` и `proekt`. Спросите «что лежит в этой папке?» — Claude ответит по карте, без поиска.

---

## Шаг 5. Завести первый проект

Напишите:

```text
/tema Проект-тест — бот, который считает отзывы сотрудников по филиалам
```

Claude задаст два вопроса, к каждому — готовый вариант ответа. Можно просто ответить «да».

1. Зачем? — *«Бухгалтер каждый месяц вручную считает отзывы для бонусов. Да?»*
2. Как поймём, что готово? — *«Бот месяц считает отзывы, и итог совпадает с ручным подсчётом. Да?»*

Claude попросит разрешение записать файлы — разрешайте.

**Появится:**

- новый файл `projects\Проект-тест.md` — карточка: зачем, как устроено, кто что делает, когда готово, что готово, что дальше;
- в `00_DASHBOARD.md`, «Проекты в работе»: строка `Проект-тест — бот в рабочем чате считает отзывы… Стадия: проектирование`;
- в `IDEAS_LOG.md`, «Разобранные»: `бот, который считает отзывы → переведена в проект Проект-тест`;
- в `Tasks Board.md`, «Сегодня»: один первый шаг.

---

## Шаг 6. План проекта

Если проект большой, напишите:

```text
/proekt Проект-тест
```

Claude покажет план: шаги по 20–30 минут с галочками, у каждого — кто делает. Ничего не меняет, пока вы не напишете «утверждаю».

**Появится после «утверждаю»:** файл `plans\<дата>-Проект-тест-план.md`, в карточке — путь к плану.

---

## Шаг 7. Один шаг — один разговор

Сделали шаг — попросите: «запиши итог в карточку». В «Что готово / Что дальше» появятся три строки: что сделали, что решили, следующий шаг.

Дальше — новый разговор в той же папке и:

```text
Продолжаем Проект-тест
```

Claude прочитает карточку и начнёт со следующего шага. Пересказывать ничего не надо.

---

## Что где лежит и зачем

Руками в эти файлы почти ничего писать не нужно: их ведёт Claude по правилам из карты и регламентов.

| Что | Зачем | Кто заполняет |
|---|---|---|
| `CLAUDE.md` | Табличка на двери: где что лежит и как тут работать. Claude читает её первой в каждом разговоре. | Вы один раз, потом правите под себя |
| `00_DASHBOARD.md` | Главная доска: какие проекты в работе и что сейчас главное. Нули в начале — чтобы файл стоял первым. | Claude: `/tema` добавляет строку проекта |
| `Tasks Board.md` | Доска задач: сегодня (не больше трёх), на неделе, потом, заморожено, готово. Открыли утром — видно три дела. | Claude: `/tema` кладёт первый шаг проекта |
| `IDEAS_LOG.md` | Банк идей, чтобы мысль не потерялась. Скажите «запиши идею…» — или Claude сам предложит. Идея пошла в работу — здесь остаётся ссылка на проект. | Claude |
| `DECISIONS_LOG.md` | Журнал решений: дата, что решили и почему. Через месяц не надо вспоминать, почему сделали так. | Claude, когда вы что-то решили |
| `projects\` | Карточки проектов: зачем, что готово, что дальше. Новый разговор начинается с чтения карточки. | Claude: `/tema` |
| `projects\_ШАБЛОН.md` | Бланк карточки, по нему заполняется новая. | Не трогать |
| `agents\` | Регламенты: как делать дело по шагам. Команда читает регламент отсюда. Хотите поменять процесс — правьте регламент. | Вы или Claude по вашей просьбе |
| `.claude\commands\` | Сами команды `/tema` и `/proekt`. | Не трогать |
| `plans\` | Планы больших проектов с галочками. | Claude: `/proekt` |
| `код\` | Программы, боты, скрипты. Карточка проекта только ссылается на папку. | Claude, когда строите бота |
| `_archive\` | Страховка: Claude ничего не стирает, а откладывает сюда. Ошибся — файл можно вернуть. | Claude |

**Тема и проект.** Тема — мысль из разговора («хочу бота для отзывов»). `/tema` превращает её в проект — карточку в `projects\`. Путь такой: идея (`IDEAS_LOG`) → проект (`projects\`) → дело стало повторяться → регламент (`agents\`) и команда к нему.

---

## Если что-то не так

- **Нет команд `/tema` и `/proekt`** — вы в старом разговоре. Откройте новый (шаг 4).
- **Claude пишет, что файл уже есть** — в папке что-то лежало. Начните с пустой папки или скажите ему, что делать с этим файлом.
- **Вместо русских имён файлов «кракозябры»** — скажите Claude: «имена файлов из заготовки распаковались неправильно, распакуй заново с кодировкой UTF-8».
