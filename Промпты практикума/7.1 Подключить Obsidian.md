# 7.1 — Подключить Obsidian

Слайд 38 презентации · раздатка «7 — Obsidian.pdf» · [все промпты по порядку](README.md)

**Что получится:** Obsidian показывает вашу базу: дашборд, граф связей между заметками, доска задач карточками.

## Что нажать

1. Сайт obsidian.md → Download → Windows → установите — бесплатно, регистрироваться не нужно
2. Откройте Obsidian → «Открыть папку как хранилище» → выберите D:\МойБизнес → «Доверять автору» — это та же папка, где работает Claude
3. Закройте Obsidian. Claude → вкладка Code → папка базы → вставьте промпт 7.1 → Enter → «Разрешить»
4. Откройте Obsidian снова: дашборд, граф (Ctrl + G)
5. Доска задач: Настройки (шестерёнка внизу слева) → «Сторонние плагины» → «Включить» → «Обзор» → Kanban → «Установить» → «Включить». Откройте Tasks Board

## Промпт

Наведите мышку на серое поле с текстом — справа вверху появится значок «скопировать» (два квадратика). Нажмите его: промпт скопирован целиком. Вставьте в Claude и нажмите Enter.

```text
Подготовь мою базу к Obsidian — бесплатной программе для заметок, которая открывает эту же папку. Я не программист: объясняй просто и перед каждым действием жди моего «да».

Сначала проверь, что ты в папке моей базы: в ней есть CLAUDE.md и 00_DASHBOARD.md. Если нет — остановись и скажи, в какой папке мы.
Попроси меня закрыть Obsidian, если он открыт: пока он работает, он перезаписывает свои настройки.

Что сделать:
1. Служебная папка Obsidian — .obsidian в корне базы. Нет её — создай.
2. Граф (картинка связей между заметками), файл .obsidian\graph.json: группы цветов по папкам — projects, Отделы, agents, plans — каждой свой цвет, и отдельный цвет для 00_DASHBOARD, «Досье бизнеса» и «Разбор бизнеса». Папки код и _archive в графе не показывай. Файл уже есть — дополни, остальные настройки не трогай.
3. Вложения (картинки, файлы, которые я вставлю в заметки) — в папку «Вложения»: настройка в .obsidian\app.json, тот же принцип.
4. Проверь ссылки. В 00_DASHBOARD.md должны быть ссылки вида [[Название]] на все проекты из projects и все отделы из Отделы. Чего не хватает — покажи списком и добавь после моего «да». Ссылки, которые ведут на несуществующий файл, — покажи списком.
5. Ничего не удаляй и не переименовывай.

В конце скажи мне коротко: откройте Obsidian → «Открыть папку как хранилище» → эта папка; граф — Ctrl + G. Перед словом «готово» прочитай записанные файлы с диска.
```
