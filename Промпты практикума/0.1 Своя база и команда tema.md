# 0.1 — Своя база и команда /tema

Слайд 21 презентации · раздатка «4 — Карта своего бизнеса.pdf» · [все промпты по порядку](README.md)

**Что получится:** Папка-база для Claude: карта базы, дашборд, доска задач, шаблон проекта и команды /tema и /proekt.

## Что нажать

1. Создайте папку D:\МойБизнес. Claude → вкладка Code → эта папка
2. Вставьте строку справа → Enter. На вопросы — «Разрешить» — Claude скачает заготовку: карту базы, дашборд, доску задач, шаблон проекта
3. Откройте новый разговор в этой папке и наберите / — в списке появятся команды tema и proekt

✓ Готово, когда в папке лежат CLAUDE.md и 00_DASHBOARD.md, а «/» показывает tema.

## Промпт

Наведите мышку на серое поле с текстом — справа вверху появится значок «скопировать» (два квадратика). Нажмите его: промпт скопирован целиком. Вставьте в Claude и нажмите Enter.

```text
Прочитай https://raw.githubusercontent.com/msattarovkzn/claude-start-proekt/main/prompts/01-zagotovka.md и сделай по этой инструкции
```

Claude прочитает по этой ссылке полную инструкцию: [prompts/01-zagotovka.md](../prompts/01-zagotovka.md). Читать её самим не обязательно.
