# 7.2 — Поставить Автопилот

Слайд 38 презентации · раздатка «7 — Моды и навыки.pdf» · [все промпты по порядку](README.md)

**Что получится:** Навык Автопилот: программа по вашей идее под ключ, с табло готовности.

## Что нажать

1. Claude → вкладка Code → папка своей базы. Вставьте промпт со следующей страницы → Enter
2. Claude спрашивает разрешения — «Разрешить». Windows спросит «Разрешить изменения?» — «Да»
3. Claude создаст пустую папку под программу и скажет её открыть: Claude → Code → эта папка — не в базе: у программы своя папка
4. В новой папке напишите /autopilot manual и идею своими словами — например: «бот, который в 10 утра напоминает мне об оплатах»
5. Отвечайте на вопросы. На задание и план — «ок». Дальше табло
6. Скачает Автопилот из интернета (GitHub). Регистрироваться и скачивать руками не нужно
7. Положит его в папку навыков Claude
8. Проверит две программы, без которых Автопилот не работает: Git — записывает историю каждой правки, Python — на нём работают его помощники. Нет — поставит сам
9. Создаст папку под первую программу

## Промпт

Наведите мышку на серое поле с текстом — справа вверху появится значок «скопировать» (два квадратика). Нажмите его: промпт скопирован целиком. Вставьте в Claude и нажмите Enter.

```text
Помоги мне поставить навык «Автопилот» для Claude Code и подготовить первую небольшую программу. Я не программист: объясняй просто, по шагам, и перед каждым действием жди моего «да».

Установка:
1. Скачай архивом открытый репозиторий github.com/nick-vels/skills (регистрация на GitHub не нужна). Из него возьми папку skills/autopilot целиком и положи в %USERPROFILE%\.claude\skills\autopilot.
2. Проверь, есть ли на компьютере Git и Python — без них Автопилот не работает. Нет — поставь через winget (встроенный установщик Windows); я подтвержу окно Windows «Разрешить изменения?». Не выйдет — дай мне ссылки и скажи, какие галочки поставить (у Python обязательно «Add Python to PATH»).
3. Скажи мне закрыть этот разговор и открыть новый, чтобы навык подхватился, и проверь, что команда /autopilot видна.

Первая программа:
4. Создай отдельную пустую папку D:\Автопилот\[название программы]. Никогда не запускай Автопилот в моей рабочей папке с базой: он ведёт там свою историю изменений.
5. Скажи, как открыть эту папку в Claude (вкладка Code), и что написать: /autopilot manual и моя идея своими словами.
6. Пароли и ключи в чат не пишу: Автопилот сам скажет, в какой файл их вписать.

Начни с плана из 5–7 шагов.
```
