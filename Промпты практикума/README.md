# Промпты практикума — по порядку

Номер промпта — такой же, как на кнопке на слайде. Первая цифра — номер раздаточного файла (PDF), вторая — номер промпта в нём.

**Как пользоваться:** откройте нужный промпт → наведите мышку на серое поле → нажмите значок «скопировать» справа вверху → вставьте в Claude (вкладка Code, нужная папка) → Enter. Регистрироваться на GitHub не нужно.

Начинать с **0.1**: без своей базы не будет команды /tema, которой заводятся новые темы.
