# 4.1 — Карта бизнеса

Слайд 22 презентации · раздатка «4 — Карта своего бизнеса.pdf» · [все промпты по порядку](README.md)

**Что получится:** Досье бизнеса, разбор: 3 сильные стороны, 3 проблемы, 3 задачи для Claude — и заметки по отделам.

## Что нажать

1. Claude → вкладка Code → новый разговор → выберите папку D:\МойБизнес — вверху видно, что работа идёт в папке МойБизнес
2. Скопируйте строку внизу, вставьте в поле ввода → Enter
3. Claude спросит разрешение открыть ссылку — «Разрешить» — он читает инструкцию с GitHub
4. Появится «Вопрос 1 из 16» — отвечайте. Так 16 раз, 20–30 минут
5. Claude попросит записать файл «Досье бизнеса» — «Разрешить». Покажет коротко: «что неверно?» — поправьте или «всё верно»
6. «Позову четырёх помощников… окно не закрывайте» — ждите 3–7 минут
7. Готово: в папке Досье, Разбор и Отделы, в чате — 3 проблемы и 3 строки /tema
8. Первая задача: новый разговор в этой папке → вставьте первую строку /tema

## Промпт

Наведите мышку на серое поле с текстом — справа вверху появится значок «скопировать» (два квадратика). Нажмите его: промпт скопирован целиком. Вставьте в Claude и нажмите Enter.

```text
Прочитай https://raw.githubusercontent.com/msattarovkzn/claude-start-proekt/main/prompts/02-razbor-biznesa.md и сделай по этой инструкции
```

Claude прочитает по этой ссылке полную инструкцию: [prompts/02-razbor-biznesa.md](../prompts/02-razbor-biznesa.md). Читать её самим не обязательно.
