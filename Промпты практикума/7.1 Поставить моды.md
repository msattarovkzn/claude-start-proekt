# 7.1 — Поставить моды

Слайд 34 презентации · раздатка «7 — Моды и навыки.pdf» · [все промпты по порядку](README.md)

**Что получится:** Три мода в Claude: Шкала, Передатчик, Прогресс по плану.

## Что нажать

1. Откройте приложение Claude → вкладка Code → папку своей базы
2. Скопируйте промпт со следующей страницы, вставьте в поле ввода → Enter
3. Claude спрашивает разрешения — нажимайте «Разрешить»
4. Claude даст команды — вставьте их по одной в PowerShell — Пуск → напечатайте PowerShell → Enter. В окне: правая кнопка мыши — команда вставилась → Enter. Ставить программы сам Claude не может — так его защищают, это нормально
5. Закройте разговор и откройте новый
6. Скачает моды из интернета по ссылке. Моды лежат на GitHub — это бесплатное хранилище программ. Регистрироваться и скачивать руками не нужно
7. Разложит их в служебную папку Claude — создаст её сам, трогать её не нужно
8. Найдёт программу Claude на вашем компьютере
9. Подключит три мода и проверит вместе с вами

## Промпт

Наведите мышку на серое поле с текстом — справа вверху появится значок «скопировать» (два квадратика). Нажмите его: промпт скопирован целиком. Вставьте в Claude и нажмите Enter.

```text
Помоги мне поставить три мода для Claude Code: «Шкала» (ctx), «Передатчик» (handoff) и «Прогресс по плану» (plan-progress). Я не программист: объясняй просто, по шагам, и перед каждым действием жди моего «да».

Где лежат: github.com/msattarovkzn/claude-mody — открытый репозиторий. Скачай его архивом сам, регистрация на GitHub не нужна.

Как действуем:
1. Распакуй архив в папку %USERPROFILE%\.claude\mody (создай её). Эту папку потом не переносить и не удалять: моды работают оттуда.
2. Найди программу Claude Code на этом компьютере. Команды claude в PowerShell обычно нет; путь к программе записан в журнале приложения %LOCALAPPDATA%\Claude\Logs\main.log, строка «Using Claude Code binary at».
3. Подключи папку mody как источник модов и поставь три мода: ctx, handoff, plan-progress.
4. Если защита Claude не даёт поставить самому — это нормально, не обходи её. Дай мне команды по одной: я открою Пуск → PowerShell, вставлю команду, нажму Enter и пришлю, что ответило.
5. Скажи мне открыть новый разговор и проверь со мной: под полем ввода видна строка с квадратиками и процентами.
6. Объясни, как выключить любой мод, если он помешает.

Начни с плана из 5–7 шагов.
```
